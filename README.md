# PayGhana Cloud

Ghana-first payroll SaaS for internal accountants, payroll teams and external auditors.

## Status

Initial repository setup. Add the current PayGhana Cloud v1.1.0 Beta source package and review production requirements before deployment.

## Important

Do not add production secrets, employee personal data, bank details, or real payroll records to this repository. Configure secrets only through your hosting provider's private environment settings.

This product is not approved for live payroll until Ghana PAYE and pension rules have been independently checked, security tested, and a complete backup/restore procedure has been demonstrated.
